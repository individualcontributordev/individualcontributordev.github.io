# Disc builder

https://individualcontributor.dev/builder/

Applies stackable `ic-layer-v1` packs from:

- CSR Pages: `/Final-Fantasy-7-CSR/builder/manifest.json`
- Modding Pages: `/Final-Fantasy-7-Modding/builder/manifest.json`

Local `manifest.json` only defines Unmodified + those `remoteSources`. Packs are not duplicated here.

Players: choose an NTSC-U `.bin`, pick a base and add-ons, build zip (`.bin` + `.cue` + `APPLIED.txt`).
